核心結論

DFF 必須依指定 NAND3 架構製作。不能改用其他架構。
ME4 可以用在 DFF。ME4 可以經過 DIFF 上方；若要接 DIFF，需完整鏈：DIFF → CONT → ME1 → VIA1 → ME2 → VIA2 → ME3 → VIA3 → ME4。
Pin 名稱與順序要和 testbench 一致。DFF_tb.sp 使用 xDFF clk D reset Q QX vdd gnd DFF。
