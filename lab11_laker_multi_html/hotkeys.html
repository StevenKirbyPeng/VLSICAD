Hot Key 查詢

Hotkey英文功能中文說明常用情境
kTag ruler標示尺規 / 放 ruler量 layout 長寬、截圖標尺寸
Shift + kClear ruler清除尺規清掉舊量測線
rCreate rectangle畫矩形畫 DIFF、PO1、ME1、NIMP、PIMP、NWELL
dMeasure distance量距離檢查寬度、間距、extension
qShow object attribute顯示物件屬性查看 layer、座標、尺寸、屬性
sStretch selected object(s)拉伸選取物件改 DIFF、Metal、Poly 長寬
cCopy selected object(s)複製選取物件複製 NMOS、PMOS、contact、layout block
mMove selected object(s)移動選取物件搬移元件或線段
DeleteDelete selected object(s)刪除選取物件刪掉錯畫的 layer 或 pin
aAlign selected object(s)對齊選取物件對齊 contact、poly、metal
fZoom all顯示全部找不到 layout 時回到全圖
Ctrl + zZoom in放大看細節、量尺寸
Shift + zZoom out縮小看整體 layout
Ctrl + aSelect all objects全選物件整個 cell 複製、搬移、刪除
Shift + rReshape selected object(s)改變選取物件形狀修改 polygon / path 形狀
F8Clear Highlight清除 highlight清掉 DRC / LVS highlight 標記
iCreate Instance建立 instance放入其他 cell，例如 PMOS/NMOS block
uUndo last action復原上一動畫錯或移錯時回復
Shift + uRedo last action重做上一動Undo 後再還原
pCreate Path畫路徑Metal 走線、長條連線
Shift + pCreate Polygon畫多邊形特殊形狀 layer
