INV Layout DRC 錯誤修正順序教學

依照目前 inv.LAYOUT_ERRORS.txt 的 DRC 結果整理。此頁先聚焦真正需要手動修改的幾何錯誤；DN、DM、LUP 類先放到「暫時排除」區。

一、總修正策略

你的錯誤核心是 VIA0 → M0_OD → CMD → OD/MD 的幾何關係沒有對齊。建議順序是：

順序錯誤為什麼先修修正重點
1VIA0.W.1.TVIA 尺寸錯會連帶造成 enclosure / covered 錯。刪除錯 VIA0，重放標準 0.032 × 0.032 µm VIA0。
2VIA0.R.9確認 VIA0 上下層關係正確，否則後面包覆修了也沒用。VIA0 必須完全在 M0_OD∩M1 或 M0_PO∩M1 內。
3VIA0.EN.2VIA 位置正確後，再調包覆距離。M0_OD 對 VIA0 兩個相對邊包覆 ≥ 0.015 µm。
4CMD.R.4.TCMD 壓到 OD/MD 會讓 CMD 延伸怎麼調都錯。把 CMD 從 OD/MD 禁止重疊區移開。
5CMD.EX.3.1解決 M0_OD 對 CMD 上下方向延伸不足。M0_OD 在 CMD 上下方向 extension ≥ 0.113 µm。
6CMD.EX.1最後微調 CMD 水平方向延伸。CMD 對 M0_OD 水平 extension = 0.025 ~ 0.10 µm。
7NP.R.3.T / PP.R.3.Timplant overlap 通常和 contact 幾何較獨立，可最後修。NP 與 PP 不可重疊，在 y≈-8.379 附近分開。

二、依序修改步驟

Step 1：先修 VIA0.W.1.T — VIA0 尺寸錯

目前錯誤 DRC 要求 VIA0 寬高必須是 0.032 × 0.032 µm，但目前有一顆約為 0.034 × 0.033 µm。

解法：不要手動畫 VIA0。刪除錯誤 VIA0，用 PDK / Contact Generator 重新放標準 VIA0。

檢查座標：錯誤在 (3.8960,-8.3180) ~ (3.9300,-8.2850) 附近。

Step 2：修 VIA0.R.9 — VIA0 沒有被合法上下層完整覆蓋

目前錯誤 VIA0 必須完全被下列其中一種組合覆蓋：{M0_PO AND M1} 或 {{M0_OD NOT CMD} AND M1}。你的 VIA0 有部分沒有落在合法重疊區內。

解法：開啟 M0_OD、M0_PO、VIA0、M1 四層，確認 VIA0 小黑方塊完全在 M0_OD 與 M1 的共同區域中，不要碰到 CMD 區域。

Step 3：修 VIA0.EN.2 — M0_OD 對 VIA0 包覆不足

目前錯誤 VIA0 被 {M0_OD NOT CMD} 包覆不足。規則要求兩個相對邊包覆 ≥ 0.015 µm，另外兩邊至少 ≥ 0.004 µm。

解法：把 VIA0 移到 M0_OD 中央，或加寬 / 加長 M0_OD。注意不要讓 VIA0 落進 CMD 區。

Step 4：修 CMD.R.4.T — CMD 不可壓到 OD/MD

目前錯誤 ALL_MD_AND_OD overlap ALL_CMD is not allowed。代表 CMD 疊到 OD/MD 區域，錯誤共有 8 個，集中在 x=3.850~3.980 附近。

解法：開啟 OD/MD 與 CMD。把 CMD 從 OD/MD 區移開，或縮短 CMD，使它不與 OD/MD 重疊。

Step 5：修 CMD.EX.3.1 — M0_OD 對 CMD 垂直延伸不足

目前錯誤 M0_OD extension on CMD in vertical direction ≥ 0.113 µm。你有 6 個位置，M0_OD 在 CMD 上下方向沒有延伸夠。

解法：在不壓到 OD/MD 的前提下，拉長 M0_OD，讓它比 CMD 上下各超出足夠距離。優先用 PDK 合法形狀，不要任意拉奇怪尺寸。

Step 6：修 CMD.EX.1 — CMD 對 M0_OD 水平延伸不在 0.025~0.10 µm

目前錯誤 CMD 對 CrtM0_OD 的水平方向 extension 必須在 0.025 ~ 0.10 µm。你的錯誤座標集中在右側 x≈4.261~4.262，代表某一邊 CMD 水平延伸太短或太長。

解法：用尺規量 CMD 左右超出 M0_OD 的距離，調到 0.025~0.10 µm 之間。建議抓中間值，例如約 0.05 µm，較安全。

Step 7：修 NP.R.3.T / PP.R.3.T — NP 與 PP implant 重疊

目前錯誤 NP overlap PP / PP overlap NP is not allowed。錯誤在 y≈-8.379 附近，是一條很薄的重疊線。

解法：開啟 NP、PP。把 NP 與 PP 邊界分開，不要剛好壓到同一條座標線。通常把其中一個 implant 邊界上移或下移一點，留下 spacing 即可。

三、暫時排除但仍需知道的錯誤

類別錯誤處理策略

四、實際操作檢查清單

  1. 在版圖中只開：M0_OD、CMD、VIA0、M1、OD/MD、NP、PP。
  2. 先使用 DRC Browser 的 Zoom To Error，不要用肉眼找。
  3. 刪掉錯誤 VIA0，重新用標準 VIA0 cell。
  4. 確認 VIA0 在 M0_OD 與 M1 重疊區中央。
  5. 把 CMD 從 OD/MD 上移開。
  6. 量測 M0_OD 對 CMD 上下 extension 是否 ≥ 0.113 µm。
  7. 量測 CMD 對 M0_OD 左右 extension 是否 0.025~0.10 µm。
  8. 最後分開 NP / PP implant 邊界。
  9. 重新跑 DRC，只看非 DN、DM、LUP 類是否消失。
