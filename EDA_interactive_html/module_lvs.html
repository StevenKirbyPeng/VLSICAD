Module 2

LVS：Layout Versus Schematic

LVS 檢查 layout 抽出的 netlist 是否與 xor.spi / schematic 一致。你目前的主要錯誤就在 LVS。

LVS 檢查規格

細項正確要求目前錯誤
Pin 名稱A、B、OUT/Y、VDD、GND 完全一致OUT / Y / F 混用
反相器輸出A→NA，B→NBNA/NB 可能沒有正確拉到 gate
MN3g=NA, d=net_n1, s=GND, b=GNDlayout 抽成 g=9, d=4
MN4g=B, d=net_n1, s=GND, b=GNDlayout 抽成 g=Y, d=4
Internal netnet_n1 必須是共同中間節點被抽成數字 4，可能未命名或接錯
你的錯誤結論

這不是單純文字 label 的問題，而是「下拉 NMOS 網路與 source netlist 連接關係不一致」。請先統一名稱，再用 Highlight Net 檢查 NA、NB、net_n1、OUT/Y。
