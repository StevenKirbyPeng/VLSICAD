Module 1

DRC：Design Rule Check

DRC 檢查版圖幾何尺寸是否合法。它不判斷 XOR 功能，只判斷製程規則是否被違反。

DRC 檢查規格

細項檢查內容錯誤例子修正方式
WidthME1/PO1/DIFF 是否太細金屬線寬小於 minimum width加寬該 layer
Spacing同層或不同層距離是否足夠兩條 ME1 太近拉開距離
Enclosurecontact 是否被 metal/diff 包住CONT 沒被 ME1 覆蓋增加包覆
OverlapPoly 是否正確跨過 diffusionMOS gate 沒形成調整 poly/diff 交疊
在 Lab10 XOR 中的意義

你的 layout 即使 DRC 通過，也只代表「畫法合法」。如果 NMOS gate 接錯、NA/NB 沒接到、OUT/Y/F 名稱混用，DRC 不一定會報錯，因為這些是 LVS 問題。
