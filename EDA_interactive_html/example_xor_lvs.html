Lab10 XOR 目前錯誤總分析

根據你提供的 LVS 截圖，目前最重要的問題是 layout 抽出的 NMOS 連線與 source netlist 不一致。

錯誤一：MN3 gate

Source 預期 g=NA，Layout 卻抽成 g=9。代表 A 的反相輸出 NA 沒有正確接到 MN3 poly gate。

錯誤二：MN4 gate

Source 預期 g=B，Layout 卻抽成 g=Y。代表 MN4 gate 接到輸出 Y，而不是輸入 B。

錯誤三：net_n1

Source 預期 drain 接 net_n1，Layout 抽成 4。代表內部共同節點未命名或連接不一致。

錯誤四：名稱混用

你圖中同時出現 OUT、Y、F。LVS 需要 pin 名稱一致，請擇一統一。

修正優先順序

  1. 輸出名稱統一：全部用 OUT 或全部用 Y。
  2. 確認 inverter A output = NA，inverter B output = NB。
  3. MN3 gate 接 NA，MN4 gate 接 B。
  4. MN3/MN4 drain 共同節點命名為 net_n1。
  5. 所有 NMOS body/source 底部接 GND。
  6. 重新跑 LVS，直到 Correct / smile face。
