Lab10 完整檢查流程
目前你這個 XOR 案例的主要錯誤
錯誤LVS 顯示真正意思修正方式
MN3 gate 錯source 要 g:NA，但 layout 抽成 9NA 沒接到 MN3 poly gateA inverter output 標成 NA，並拉到 A' gate
MN4 gate 錯source 要 g:B，但 layout 抽成 YMN4 gate 接到輸出或錯誤節點MN4 poly gate 改接輸入 B
net_n1 不一致source 要 d:net_n1，但 layout 抽成 4中間節點未命名或沒有接成同一網路MN3/MN4 drain 共同節點標成 net_n1
輸出名稱混用Y / F / OUT 同時出現source 與 layout pin 對不上統一成 OUT 或 Y，一套用到底
建議修正順序
  1. 先統一 pin：A、B、OUT、VDD、GND。
  2. 確認 A inverter output = NA；B inverter output = NB。
  3. 確認 MN3 gate=NA、MN4 gate=B。
  4. 確認 MN3/MN4 drain 共同接 net_n1。
  5. 重新跑 LVS，直到 Correct / smile face。
  6. LVS 通過後再做 PEX 與 post-sim。
