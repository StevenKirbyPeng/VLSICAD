建議閱讀順序

1

先看流程總覽

先知道這份作業要做什麼：Input、Gray、Gaussian、Otsu、Auto-Polarity、CCL、BBox、Overlay、Done。

2

再看架構圖與記憶體

搞懂 ImgROM、UrSRAM、AnsSRAM 分別存什麼，以及 top FSM 怎麼控制它們。

3

看各流程分頁

每一頁都會告訴你該段 code 的目的、重點變數、對應的結果圖與中文說明。

4

最後看逐行說明

如果要寫報告、demo 或 debug，再回到逐行頁面看更細的中文註解。

你可以怎麼用這個網站

  • 如果你要寫報告：先用流程頁面抓段落架構，再截圖流程圖與成果圖。
  • 如果你要準備 demo：先看架構頁與 CCL / Otsu 頁，這兩頁最容易被問。
  • 如果你要 debug：先看 line-by-line 頁，再搭配 pattern gallery 觀察結果。
  • 如果你要重構程式：先看 registers / helper / CCL / overlay 四頁，能最快理解資料路徑。

這一版特別把圖檔整合進來，所以你不只是在看 code，而是能把「程式行為」和「實際輸出圖」對照起來理解。
