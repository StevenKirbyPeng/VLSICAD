整體流程

Input → RGB-to-Gray → Original Backup → Histogram Clear → Gaussian Line Buffer Init → Gaussian Filtering → Histogram Construction → Otsu Thresholding → High-Pixel Counting → Auto-Polarity → Union-Find / BBox Init → CCL Line Buffer Init → Binary Mask → 8-Connected CCL → Root Label Merge → Border / Large Object Filtering → BBox Overlay → Done

這個網站不是只放 code，而是把程式、圖檔、流程、成果圖整合在一起。你可以從流程頁面看「某段 code 為什麼存在」，也可以從 Pattern 圖回頭理解前處理、mask、label、overlay 的實際效果。

首頁互動入口

01

Module 介面與記憶體協定

定義 top module 的 I/O 與 ImgROM、UrSRAM、AnsSRAM 的讀寫介面。
02

常數與 FSM State 定義

定義 GREEN、NPIX、MAX_LABELS 與所有狀態編碼。
03

內部暫存器、陣列與資料結構

包含 histogram、line buffer、union-find、bbox table 與各種控制計數器。
04

輔助函式與 Task

包含 Reflect-101、RGB-to-Gray、Gaussian、find_root、update_bbox、union_pair 等可重用邏輯。
05

CCL 組合邏輯

在 S_CCL_SCAN 狀態時，即時計算 ccl_fg、鄰居 label 與 cur_label_comb。
06

同步 always、reset 與預設控制

clock 上升緣更新主要暫存器，reset 時將系統回到初始狀態。
07

Input / RGB-to-Gray / Original Backup

S_IDLE、S_LOAD、S_GRAY：開始讀圖、轉灰階、把灰階寫入 UrSRAM，並備份原圖到 AnsSRAM。
08

Histogram Clear 與 Gaussian Line Buffer 初始化

清空 histogram，並從 UrSRAM 載入三列資料到 line buffer。
09

Gaussian Filtering 與 Histogram Construction

利用 gaussian_lb() 計算平滑灰階，同步更新 histogram 與 sum_total。
10

Otsu Thresholding

把 Otsu 計算拆成多個 state：scan、lhs、denom、square、compare。
11

High-Pixel Counting 與 Auto-Polarity

統計 histogram 中大於 otsu_t 的 pixel 數量，若超過半張圖就反相。
12

Union-Find / BBox Table 初始化

初始化 parent[]、bbox_valid[]、bbox_border[] 以及 bbox 座標表。
13

CCL Line Buffer 初始化與 8-Connected CCL 掃描

重新載入 CCL line buffer，並在 S_CCL_SCAN 中做 binary mask、label assignment、union 與 bbox update。
14

CCL 跨列更新與 Root Label Merge

處理 CCL line buffer row update，以及把非 root label 的 bbox 合併回 root label。
15

物件過濾、BBox Overlay 與特殊補框

排除邊界物件與太小物件，再把有效 bbox 畫成綠色框；某些情況還有 special box compensation。
16

Done 與 Testbench 驗證觀念

S_DONE 拉高 done，testbench 再接手做 golden image comparison。
