# drawBbox 互動式多網頁閱讀包

## 內容特色
- 更漂亮的深色玻璃風格介面
- 多網頁架構，方便分主題閱讀
- 整合 assets.zip 內的流程圖、架構圖、pattern 圖與結果圖
- 逐段流程說明 + 逐行中文說明
- 可搜尋、可展開收合、可切換頁籤、可點圖放大

## 主要頁面
- index.html：首頁
- pages/guide.html：閱讀導覽
- pages/flow_overview.html：流程總覽
- pages/architecture.html：架構圖與記憶體
- pages/pattern_gallery.html：Pattern 結果圖
- pages/code_map.html：程式總覽
- pages/line_by_line.html：逐行說明
- pages/stages/*.html：16 個流程分頁

## 原始碼
- drawBbox_original.v：原始程式碼，未修改
- drawBbox_annotated_every_line.v：每行附中文說明註解版

直接打開 index.html 即可開始瀏覽。
