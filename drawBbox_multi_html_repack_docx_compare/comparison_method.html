此頁把「比較的方法.docx」中的所有流程對照內容放入多網頁系統，包含單一 FSM 版、declaration_comments 版、single_submit 版，以及前面版本差異。

回首頁三版本差異表

drawBbox(21).v

流程名稱對應 state / module和 code 的關係
InputS_LOADS_LOAD 會打開 ImgROM，用 Img_A 依序讀入 256×256 的 RGB pixel
RGB-to-GrayS_LOAD在 S_LOAD 中呼叫 gray_round_rgb(Img_Q)，把 RGB 轉成灰階
Original Image BackupS_LOAD同一個 state 把原始 Img_Q 寫入 AnsSRAM，之後畫框會直接畫在原圖上
Histogram InitializationS_HIST_CLEAR清空 hist[0] 到 hist[255]，避免上一張圖的資料殘留
Line Buffer InitializationS_LB_INIT從 UrSRAM 讀灰階資料，載入 3-row line buffer，準備做 Gaussian
Gaussian FilteringS_GAUSS_HIST呼叫 gaussian_lb(x_i)，用 3×3 Gaussian kernel 計算平滑後的灰階值
Line Buffer Row UpdateS_LB_ROW每掃完一列，就從 UrSRAM 載入下一列，並旋轉 lb_prev_sel / lb_curr_sel / lb_next_sel
Histogram ConstructionS_GAUSS_HISTGaussian 後的值 base_i 會累加到 hist[base_i]
Otsu InitializationS_OTSU_INIT初始化 Otsu 需要的 wb_acc、sum_b_acc、otsu_idx、best_num、best_den
Otsu ThresholdingS_OTSU_SCAN → S_OTSU_CMP2用多個 state 分段計算 Otsu，最後得到最佳 threshold otsu_t
High-Pixel CountingS_COUNT_HI統計 histogram 中大於 otsu_t 的 pixel 數量
Auto-Polarity SelectionS_POLARITY根據 count_hi > 32768 判斷是否設定 invert_sel
Union-Find / BBox Table InitializationS_PARENT_INIT初始化 parent[]、bbox_valid[]、bbox_border[]、bbox_xmin/xmax/ymin/ymax[]
CCL Line Buffer InitializationS_LB_INIT2CCL 前重新載入 3-row line buffer，因為 CCL 也要用 Gaussian 後的 mask
Binary Mask GenerationS_CCL_SCAN在 CCL 掃描時即時計算 ccl_base > otsu_t，再根據 invert_sel 決定 foreground
Connected Component LabelingS_CCL_SCAN檢查 W, NW, N, NE 四個鄰居，執行 8-connected CCL
Line Buffer Row UpdateS_LB_ROW2CCL 每掃完一列，就更新 CCL 用的 line buffer
Bounding Box ExtractionS_CCL_SCAN在 CCL 過程中呼叫 update_bbox_task()，同步更新 bbox
Root Label MergeS_BBOX_INITCCL 完成後，把被 union 的 label 的 bbox 合併回 root label
Border Object RejectionS_BOXMAP_GEN如果 bbox_border[label_idx] = 1，代表物件碰到邊界，直接跳過不畫
Large Object FilteringS_BOXMAP_GEN呼叫 is_large_bbox()，只保留寬高都大於等於 16 的 bbox
Bounding Box OverlayS_BOXMAP_GEN把合格 bbox 的上下左右邊寫成 GREEN = 32'h0000_FF00 到 AnsSRAM
Special Box CompensationS_BOXMAP_GEN如果 first_pixel == 32'h00af89d2，額外畫兩個固定位置的補償框
DoneS_DONEdone_r <= 1'b1，表示 RTL 處理完成
Golden Image ComparisonTestbench不在 drawBbox.v 裡，是 testbench 在 done 後比對輸出與 golden image

Auto-Polarity Selectionpolarity_v21_fast依照亮暗 pixel 數量決定 polarity
Binary Mask GenerationST_CCL / ccl_v21_fastCCL 階段根據 threshold 與 polarity 產生 foreground/background
Connected Component Labelingccl_v21_fast使用 label buffer 和 equivalence table 做 CCL
Equivalence Table Mergeccl_v21_fast用 eq_table 合併等價 label
Label Result Writeccl_v21_fast把 label 結果寫入 AnsSRAM
Bounding Box ExtractionST_BOX / boxing_v21_fast掃描 AnsSRAM 的 label 結果，找出每個 label 的 min_x/max_x/min_y/max_y
Original Image Copyboxing_v21_fast從 ImgROM 讀原圖，複製到 AnsSRAM
Border Object Rejectionboxing_v21_fast若 bbox 碰到影像邊界，則跳過不畫
Large Object Filteringboxing_v21_fast只保留寬高大於條件的 bbox
Bounding Box Overlayboxing_v21_fast將 bbox 四條邊寫成 32'h0000_FF00 綠色
Donebox_doneboxing 完成後，top module 的 done = box_done

drawBbox_single_submit(6).v

流程名稱對應 state / module和 code 的關係
InputST_THRES / thresholdthreshold module 透過 Img_addr 從 ImgROM 讀取原始 RGB pixel
RGB-to-Graythreshold使用 19595R + 38470G + 7471B 的 Q16 權重公式，把 RGB 轉成 gray
Gaussian Window Fetchthreshold state 1用 get_data_state 依序取得 u1~b3 九個鄰近 pixel
Gaussian Filteringthreshold state 2用 [1 2 1; 2 4 2; 1 2 1] / 16 計算 gaussian_value
Gaussian Gray Write to UrSRAMthreshold state 2把 gaussian_value 寫入 UrSRAM
Histogram Constructionthreshold state 2使用 gray_level[gaussian_value] <= gray_level[gaussian_value] + 1 統計 histogram
Otsu Thresholdingthreshold state 3掃描 threshold candidate，使用 cross multiplication 比較 Otsu score
High-Pixel CountingST_POL / polarity讀取 UrSRAM 的 Gaussian gray，和 threshold 比較並計數
Auto-Polarity Selectionpolarity DONE根據 counter 結果輸出 polarity
Binary Mask GenerationST_CCL / ccl根據 img_Q[7:0]、threshold、polarity 產生 bin_img_Q
Connected Component Labeling Pass 1ccl READ_PASS_1 / WRITE_PASS_1讀取 binary image，檢查鄰居 label，產生初步 label
Equivalence Table Mergeccl WRITE_PASS_1使用 eq_table 合併不同 label 的等價關係
Label Result Write Pass 1ccl WRITE_PASS_1把 pass 1 的 label 寫入 AnsSRAM
Equivalence Table Flattenccl FLATTEN_TABLE將 eq_table 轉成連續 root label
Label Result Rewrite Pass 2ccl READ_PASS_2 / WRITE_PASS_2讀回 AnsSRAM label，再用 flatten 後的 eq_table 改寫成 root label
Bounding Box ExtractionST_BOX / boxing SCAN掃描 AnsSRAM label map，更新每個 label 的 min_x/max_x/min_y/max_y
Original Image Copyboxing COPY從 ImgROM 讀原始 RGB，寫回 AnsSRAM 作為最後輸出底圖
Border Object Rejectionboxing BOX_IDLE如果 bbox 碰到邊界，例如 min_x = 0 或 max_x = 255，就跳過
Small Object Filteringboxing BOX_IDLE如果寬高太小，例如寬或高沒有大於 10，就跳過
Bounding Box Overlayboxing BOX_WRITE_1~4將 bbox 的上下左右邊寫成 32'h0000_FF00 綠色
Doneboxing DONE / box_donedone <= 1'b1，top-level done = box_done
Golden Image ComparisonTestbench不在 RTL 內，是 testbench 在 done 後比對 golden image
