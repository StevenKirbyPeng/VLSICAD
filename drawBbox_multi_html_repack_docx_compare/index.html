SVG 流程圖

流程入口

01

Input

讀取原始 RGB 影像資料，是整個 drawBbox pipeline 的起點。

 02

RGB-to-Gray

將 RGB pixel 轉換為灰階值，作為後續 Gaussian、Otsu 與 CCL 的基礎。

 03

Original Image Backup

保留原始 RGB 影像，讓最後 bbox 可以直接畫在原圖上。

 04

Histogram Initialization

清空 histogram，避免舊影像的灰階統計污染新影像。

 05

Line Buffer Initialization

建立或載入 Gaussian 所需的影像列資料。

 06

Gaussian Window Fetch

取得 Gaussian 需要的 3×3 鄰近像素視窗。

 07

Gaussian Filtering

使用 3×3 Gaussian kernel 平滑影像。

 08

Line Buffer Row Update

每處理完一列後更新 line buffer 或 selector。

 09

Gaussian Gray Write to UrSRAM

將 Gaussian 後的灰階結果暫存到 UrSRAM。

 10

Histogram Construction

累加灰階分布，提供 Otsu threshold 計算使用。

 11

Otsu Initialization

初始化 Otsu 門檻計算的累加器與比較變數。

 12

Otsu Thresholding

掃描 threshold candidate 並找出最佳分割門檻。

 13

High-Pixel Counting

統計高於 threshold 的像素數量。

 14

Auto-Polarity Selection

判斷是否需要反相 foreground/background。

 15

Union-Find / BBox Table Initialization

初始化 CCL 與 bbox 相關資料表。

 16

CCL Line Buffer Initialization

初始化 CCL 階段所需的 line buffer。

 17

Binary Mask Generation

根據 threshold 與 polarity 產生 binary foreground mask。

 18

Connected Component Labeling

將相連的 foreground pixels 標成同一個 component。

 19

Connected Component Labeling Pass 1

第一階段 CCL，產生 provisional labels。

 20

Equivalence Table Merge

合併不同 provisional labels 的等價關係。

 21

Label Result Write

將 label result 寫入 AnsSRAM 或 label map。

 22

Label Result Write Pass 1

將第一階段 provisional label 寫入記憶體。

 23

Equivalence Table Flatten

將 equivalence table 壓平成 root label。

 24

Label Result Rewrite Pass 2

第二階段將 provisional label 轉成 root label。

 25

Bounding Box Extraction

計算每個 component 的 xmin、xmax、ymin、ymax。

 26

Root Label Merge

將非 root label 的 bbox 合併回 root label。

 27

Original Image Copy

複製原始 RGB 影像作為最後輸出底圖。

 28

Border Object Rejection

排除碰到邊界的 component。

 29

Large Object Filtering

只保留足夠大的 bbox。

 30

Small Object Filtering

排除過小或疑似雜訊的物件。

 31

Bounding Box Overlay

把有效 bbox 畫成綠色邊界。

 32

Special Box Compensation

針對特定 pattern 或特定條件額外補框。

 33

Done

RTL 完成處理並拉高 done 訊號。

 34

Golden Image Comparison

testbench 在 done 後比對輸出與 golden image。
