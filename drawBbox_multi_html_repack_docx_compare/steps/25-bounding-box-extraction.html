三個版本在此流程中的比較內容說明

在「Bounding Box Extraction」流程中，三個版本都能對應到功能實作，但組織方式不同。Single FSM 版把功能集中在 S_CCL_SCAN，屬於 state-level 的集中控制。Modular v21 版對應到 ST_BOX / boxing_v21_fast，通常由 top FSM 啟動特定子模組處理。Single Submit 版對應到 ST_BOX / boxing SCAN，雖然整份 code 合併在同一個檔案中，但功能仍由相對應的 module 或 internal state 完成。因此比較重點不是功能有沒有做，而是硬體排程方式、記憶體控制權與模組邊界不同。

//          供 Gaussian filter 計算使用，不需讀 SRAM

//      讓 DC/Presto 合成更乾淨

// 合成效益：
//   gray_mem：524,288 FF → 0 FF（改用 UrSRAM）
//   linebuf：0 → 768 FF（3行暫存）
//   淨減少：約 523,520 個 FF，合成時間大幅縮短
//
// 時序成本：
//   每列（256 pixels）結束後需讀入下一列（3-phase SRAM read × 256 col）
//   每列額外成本 = 256 × 3 = 768 cycles
