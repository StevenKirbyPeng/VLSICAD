三個版本在此流程中的比較內容說明

在「Connected Component Labeling Pass 1」流程中，三個版本都能對應到功能實作，但組織方式不同。Single FSM 版把功能集中在 S_CCL_SCAN，屬於 state-level 的集中控制。Modular v21 版對應到 ccl_v21_fast，通常由 top FSM 啟動特定子模組處理。Single Submit 版對應到 ccl READ_PASS_1 / WRITE_PASS_1，雖然整份 code 合併在同一個檔案中，但功能仍由相對應的 module 或 internal state 完成。因此比較重點不是功能有沒有做，而是硬體排程方式、記憶體控制權與模組邊界不同。
