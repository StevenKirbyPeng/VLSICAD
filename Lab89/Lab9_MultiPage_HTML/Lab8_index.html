多網頁互動式 Lab9 作業說明

本作業目標是接續 Lab8 的 NAND / NOR pre-sim，使用 Laker 完成 layout，接著通過 DRC、LVS、PEX，最後進行 post-layout simulation，並比較 pre-sim 與 post-sim 波形差異。

作業核心目的

1. 從電路到版圖

Lab8 已完成 transistor-level netlist 與 pre-sim。Lab9 要把 NAND、NOR 真的畫成 layout，包含 PMOS、NMOS、DIFF、PO1、CONT、ME1、NWELL 等圖層。

2. 驗證 layout 正確性

DRC 檢查幾何設計規則；LVS 確認 layout 抽出的電路與 schematic / spice netlist 一致；PEX 抽取寄生電容與電阻。

3. 比較 pre-sim / post-sim

post-sim 加入 layout 寄生效應，因此波形可能有較明顯的 rise / fall delay，這是 layout 對實際電路速度影響的重點。
